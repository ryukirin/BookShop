# Legacy Baseline

旧系统当前的可观察行为，只记录事实。行为是保留、修改还是去掉，由 migration-strategy.md 决定。

本次盘点没有运行旧系统：本机没有 Java、Tomcat、MySQL，原来的表结构和数据也缺失（GAP-001、GAP-002）。所以下面的条目全部是从代码读出的 STATIC 行为。文中 URL 都相对于上下文路径 `/BookShop`。

第二次盘点时，仓库里多了一份推定的复原库（`BookShop/db/`）。据 `legacy-db-reconstruction.md`，DAO 原文 SQL 已经在 MySQL 8.0.36 上对复原库回放过。那只是在推定的库上执行 SQL，不是运行旧系统，所以相关条目仍然标为 STATIC；凡是依赖复原库的结论，都会注明“按复原库”。本次盘点没有复跑这次回放。
