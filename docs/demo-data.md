# 演示数据说明

`python -m bookshop_web init-db` 会建库，并导入下面这些演示数据（GAP-002、REQ-DATA-003）。

**这些不是原书店的数据。** 原数据库已经丢失。演示数据从 `BookShop/db/seed.sql` 转写而来（`bookshop_web/seed/seed_data.py`），依据和可信度见 `migration-plans/bookshop/legacy-db-reconstruction.md`。规格、测试和验收都不得把这些值当作旧系统的事实（MIG-RULE-015）。

## 内容

| 项目 | 内容 | 是否原值 |
|---|---|---|
| 分类 | 小说（tid 1）、散文（tid 2）、诗歌（tid 3） | 否：按书的体裁推测 |
| 书籍 | 10 本，bid 为 1～9 和 11，沿用封面文件编号（仓库里没有 b10） | 书名和出版社大多读自封面，个别是推定的 |
| 价格、库存 | 每本库存 100，价格见 `seed_data.py` | 否：占位值 |
| 简介 | 作者、译者、丛书名来自封面，国籍和体裁是补写的 | 否：整段是占位文字 |
| 封面 | `b1.jpg`～`b9.jpg`、`b11.jpg`，初始化时复制到数据目录的 `covers/` 下 | 与旧系统的图片逐字节相同；版权属于各原出版方，只作演示用（COMP-019） |
| 管理员 | `admin`，role 为 2 | 口令由初始化时设置，见下文 |
| 会员、订单 | 无 | 历史数据无法恢复，不迁移 |

`b6.jpg` 和 `b8.jpg` 的内容其实是 PNG，系统按文件头识别类型，不看扩展名（COMP-012）。

## 管理员口令

管理员口令只能用下面两种方式提供，不接受命令行参数：

- 环境变量 `BOOKSHOP_ADMIN_PASSWORD`；
- 在交互终端里运行 `init-db`，按提示输入两次（不回显）。

口令不能为空，不能是 `123456`，长度不超过 64 个字符。用环境变量提供时，初始化完成后请把它清掉。

## 重新初始化

`init-db` 发现数据库已存在时会拒绝执行，不会覆盖。确实需要从头开始时，请先停止服务、备份数据目录，再删除数据目录里的 `bookshop.db`（以及 `bookshop.db-wal`、`bookshop.db-shm`），然后重新运行 `init-db`。
