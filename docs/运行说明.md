# BookShop 运行说明

本文适用于 Flask 迁移版（openspec change `migrate-bookshop-to-flask`）。旧的 Java 版在 `BookShop/` 目录中原样保留，只作参考，不再运行。

## 1. 运行环境

- **系统**：只支持 Windows（MIG-DEC-004、MIG-DEC-011）。
- **Python**：必须是 3.12.10（MIG-DEC-009）。一律用 `py -3.12` 创建虚拟环境，不要用 PATH 上的 `python`（它可能是别的版本）。服务启动时会自检版本，不符合就拒绝启动。
- **已接受的风险（COMP-001）**：3.12.10 之后的 3.12 安全更新只发布源码，没有 Windows 安装包，所以本机的 Python 拿不到这些补丁。为缩小暴露面，服务默认只监听 `127.0.0.1`。不要随意改成对外监听。

## 2. 安装

在仓库根目录执行：

```powershell
py -3.12 -m venv .venv
.venv\Scripts\python.exe -m pip install --require-hashes -r requirements.txt
```

依赖版本由哈希锁定（MIG-RULE-014）。如需重新生成锁文件，见 `requirements.in` 文件头的说明。

## 3. 配置

把 `config.example.ps1` 复制到**仓库之外**，比如 `$HOME\bookshop-config.ps1`，填好后在当前 PowerShell 会话里执行 `. $HOME\bookshop-config.ps1`。

| 环境变量 | 说明 | 默认值 |
|---|---|---|
| `BOOKSHOP_DATA_DIR` | 数据目录，里面放数据库、封面、日志和 PID 文件。必须已经存在、可写，并且放在仓库之外 | 无，必填 |
| `BOOKSHOP_SECRET_KEY` | 会话签名密钥，至少 32 字节随机值；不能用示例值 | 无，必填 |
| `BOOKSHOP_HOST` | 监听地址 | `127.0.0.1` |
| `BOOKSHOP_PORT` | 监听端口 | `8080` |
| `BOOKSHOP_ADMIN_PASSWORD` | 只在 `init-db` 时使用的管理员口令，用完请清掉 | 无 |

生成密钥：

```powershell
.venv\Scripts\python.exe -c "import secrets; print(secrets.token_hex(32))"
```

检查配置是否合规（不启动服务）：

```powershell
.venv\Scripts\python.exe -m bookshop_web check
```

## 4. 初始化数据库

```powershell
$env:PYTHONUTF8 = "1"
.venv\Scripts\python.exe -m bookshop_web init-db
```

- **管理员口令**：取自 `BOOKSHOP_ADMIN_PASSWORD`。没有设置这个变量时，命令会在终端里提示输入两次，输入内容不回显。不接受命令行参数，口令不能为空、不能是 `123456`、不超过 64 个字符。
- **导入的数据**：3 个分类、10 本演示书及其封面，以及管理员 `admin`。这些都是演示占位数据，不是原书店的数据，详见 `docs/demo-data.md`。
- **不会覆盖**：数据库已存在时，命令会拒绝执行。

## 5. 启动与停止

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\start.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\stop.ps1
```

两个脚本都可以加 `-ConfigPath <配置文件>`，在脚本内加载配置。

- **启动过程**：`start.ps1` 先执行一次 `check`，有配置错误会直接显示出来；然后在后台以隐藏窗口启动 waitress，把 PID 写到 `<数据目录>\run\bookshop.pid`，等端口可以连接后返回。
- **访问地址**：`http://127.0.0.1:8080/BookShop/`。
- **日志**：写在 `<数据目录>\logs\bookshop.log`，自动轮转，每个文件 5 MiB，保留 5 个。日志里只有请求方法、路径、状态码和异常类型，不含口令、表单值和 SQL。

## 6. 备份与恢复

数据全部在数据目录里：`bookshop.db`（以及运行时的 `-wal`、`-shm`）、`covers\`、`logs\`。

- **备份**：先执行 `stop.ps1` 停服，再整体复制数据目录。
- **恢复**：先停服，删掉数据目录里的 `bookshop.db*`，把备份中的 `bookshop.db` 和 `covers\` 复制回来，然后再启动。

上述流程由 TEST-044 自动演练。

## 7. 切换与回滚

- **切换步骤**：
  1. 确认 CI 为绿色；
  2. 打上 `pre-cutover` 标签；
  3. 在正式数据目录执行 `init-db`；
  4. 执行 `start.ps1`；
  5. 做冒烟检查：首页 200，登录页 200，未登录访问 `/BookShop/jsp/my.jsp` 会跳到登录页，`/BookShop/img/b1.jpg` 200；
  6. 停服，备份，再启动。
- **回滚步骤**：
  1. 执行 `stop.ps1`；
  2. 从最近一次备份恢复数据目录；
  3. 必要时把代码检出到上一个可用版本（如 `pre-cutover`），重新执行第 2 节的安装；
  4. 再启动。
- **不能回到 Java 版**：旧的 Java 版无法运行，回滚只能回到新系统的上一个版本。

## 8. 开发与测试

```powershell
.venv\Scripts\python.exe -m pip install --require-hashes -r requirements-test.txt
$env:PYTHONUTF8 = "1"
.venv\Scripts\python.exe -m pytest
```

- **测试分层**：`tests\unit`、`tests\web`（Flask 测试客户端）、`tests\server`（真实 waitress，带 `server` 标记）、`tests\static`（仓库扫描）。
- **批次标记**：`tests\conftest.py` 中的 `CURRENT_BATCH` 决定哪些批次的用例按“先红后绿”处理。所有批次都已完成后，它应等于 8。
- **CI**：GitHub Actions 的 `bookshop-ci` 在 `master` 分支的 push 和 pull request 上运行，环境是 windows-latest 加 Python 3.12.10。除了测试，还会跑迁移 gate 的 coverage 和 lint。

## 9. 常见问题

| 现象 | 处理 |
|---|---|
| `start.ps1` 提示 Configuration check failed | 按上面的提示改环境变量，可以先用 `python -m bookshop_web check` 单独确认 |
| 端口被占用 | 设置 `BOOKSHOP_PORT` 换一个端口 |
| 页面报 500 | 查看 `logs\bookshop.log` 中带 `unhandled` 的记录，那里有异常类型和请求路径 |
| 提示 BookShop is already running | 先执行 `stop.ps1`；如果进程已经不在了，脚本会自动清理过期的 PID 文件 |
| 上传封面返回 413 | 文件超过 5 MiB；只接受 PNG 和 JPEG |
